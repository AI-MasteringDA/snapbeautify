Về cảnh báo bảo mật của Windows

Đừng lo — đây là chuyện bình thường. Đây là cách xử lý.

Tại sao lại có cảnh báo?

SnapBeautify là app mới từ developer độc lập. Để Windows hết cảnh báo, app phải được ký bởi EV Code Signing Certificate (~$300-700/năm) — Microsoft thu phí này để xác thực danh tính các công ty lớn như Slack, Discord, Notion.

Toàn bộ source code của app công khai 100% trên GitHub — bạn có thể đọc từng dòng. Chỉ là một tool screenshot bình thường. Cảnh báo này Windows hiện cho mọi publisher mới, không riêng gì app này.

Cách cài — vượt qua 2 cảnh báo

📥 Bước 1 — Lúc đang tải về (trình duyệt)

  1. Trình duyệt có thể báo:
    "SnapBeautify-Setup.exe isn't commonly downloaded"
  2. Di chuột vào file đang tải → bấm ••• hoặc mũi tên ↑ → chọn
    "Keep" (Chrome) hoặc "Keep anyway" (Edge)

▶️ Bước 2 — Lần đầu chạy file (Windows)

  1. Double-click file vừa tải SnapBeautify-Setup.exe
  2. Hiện dialog xanh "Windows protected your PC" →
    bấm "More info" → "Run anyway"

Bạn chỉ thấy 2 cảnh báo này 1 lần duy nhất khi cài lần đầu. Mọi update tự động sau đó hoàn toàn im lặng.

Mọi thứ bạn cần để làm đẹp 1 cái screenshot.

🎨

Gradient & theme

10+ preset gradient phong cách Savvy, kèm editor tùy chỉnh đầy đủ — linear hoặc radial, tùy góc, không giới hạn số màu. Lưu được preset riêng.

🖼️

Frame cửa sổ

Đóng khung ảnh trong style macOS, Windows, hoặc trình duyệt chỉ với 1 click.

✏️

Công cụ vẽ chú thích

Bút, mũi tên, hình chữ nhật, ellipse, chữ, và blur kéo vùng để che thông tin nhạy cảm. Ctrl+Z để undo.

⌨️

Phím tắt toàn cục

Ctrl+Shift+4 chụp 1 vùng. Ctrl+Shift+6 chụp toàn màn hình. Hoạt động ngay cả khi app ẩn.

🖐️

Di chuyển ảnh tự do

Kéo ảnh bằng tool bàn tay (Ctrl+H), hoặc snap vào lưới 9 vị trí cố định.

🚀

Chụp native 4K

Chụp ở độ phân giải pixel gốc của màn hình — ảnh sắc nét kể cả trên màn hình HiDPI.

💾

Profile & preset

Lưu các cài đặt yêu thích thành profile có tên. Thêm gradient tự thiết kế vào thư viện preset cá nhân.
