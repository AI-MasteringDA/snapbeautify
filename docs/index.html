About the Windows security warning

Why does it happen?

SnapBeautify is a brand-new app from an independent developer. To remove the warning, an app needs an EV Code Signing Certificate (~$300-700/year) — Microsoft charges that fee to large companies like Slack, Discord, and Notion to verify their identity.

The app source code is 100% open on GitHub — you can read every line. It's just a screenshot tool. The warning is a generic Windows precaution for any new publisher.
